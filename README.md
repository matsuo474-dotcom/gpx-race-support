# GPXレースサポート

GPXファイルを読み込んで、地図にコースを表示し、GPSの現在地をコース上と高低図に表示するWebアプリです。ウルトラマラソンなどの長距離レース中の現在地確認に使えます。

## 使い方

1. このページ（GitHub PagesのURL）をスマホで開く
2. 「GPXを読み込む」からレースのコースGPXファイルを選ぶ
3. 「現在地を表示」を押して、位置情報の利用を許可する
4. コース上の現在地点（○km地点）・残り距離・次の目印（ウェイポイント）までの距離・高低図上の現在地が表示されます
5. 高低図をタップすると、その地点が地図に表示されます

GPXにウェイポイント（エイドステーション等）が含まれていれば、地図と「次の目印まで」に表示されます。

## プライバシー

GPXファイルと位置情報は、すべてお使いの端末のブラウザ内だけで処理されます。サーバーへの送信は一切ありません（地図の表示に OpenStreetMap のタイル画像を読み込む通信のみ発生します）。

## 動作環境

- モダンブラウザ（Chrome / Safari 等）とHTTPS接続が必要です（位置情報APIの仕様のため）
- 画面を閉じると位置の追跡は止まります
- GPSを継続使用するため、長時間の使用は電池を消費します

## 技術メモ

- 単一の `index.html` のみで動作します（地図ライブラリ Leaflet と OpenStreetMap タイルをCDNから読み込み）
- GitHub Pages にそのまま置けます
